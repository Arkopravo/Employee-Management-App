Employee Management System

A full-stack Employee Management System built using Angular, ASP.NET Core Web API, Entity Framework Core, and SQL Server. This application provides a modern and responsive interface for managing employee records with secure login functionality and complete CRUD operations.

🚀 Features 🔐 Employee Login Authentication ➕ Add New Employees ✏️ Update Employee Details 🗑️ Delete Employees 📋 View All Employees 🔍 Search and Filter Employees 📄 Pagination Support 📊 Sorting by Multiple Fields ✅ Input Validation using Data Annotations 🎨 Responsive Bootstrap UI 🔗 RESTful ASP.NET Core Web API 💾 SQL Server Database with Entity Framework Core 🛠️ Tech Stack
